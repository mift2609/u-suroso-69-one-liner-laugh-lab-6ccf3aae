One original funny line answering the prompt: the excuse a robot vacuum gives after eating a sock. The vacuum doesn't deny it — it reframes the crime as a public service.

## The line

> I didn't eat your sock — I was just giving it the deep clean it clearly needed after living under your bed for a month.

## How it works

`main.py` (Python 3, standard library only) writes the line to `/output/entry.txt`, asserts it is a single line of 1–200 characters, re-reads the file to verify what was written, and prints the line with its character count.

```sh
python3 main.py
```
